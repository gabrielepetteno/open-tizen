# Dati privati e istruzioni di sistema

Non includere segreti nelle segnalazioni pubbliche. Se rilevi un tuo dato esposto interrompi la condivisione e usa i canali privati del servizio o del titolare; questa repository non offre raccolta privata di log.

La guida è indipendente e non raccoglie credenziali né firma pacchetti per altri dispositivi. Gli esempi inclusi non rimappano Home, non abilitano root, non aprono firewall e non configurano server di rete. Il builder genera un archivio locale non firmato.

Per problemi del software citato segui la procedura del progetto upstream corretto e redigi i dettagli sensibili prima di condividerli.
