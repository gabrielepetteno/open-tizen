# Contribuire alla guida Samsung Tizen

Riporta una prova riproducibile usando il modello delle issue. Distingui installazione, apertura, riproduzione, lingua e ritorno Home.

## Dati utili

Modello commerciale, Tizen, firmware, app/versione/variante, data, passi minimi, esito atteso e osservato. Indica il valore precedente delle impostazioni cambiate.

## Dati da omettere

Seriale, MAC, DUID, indirizzi IP, password, token, URL personali degli add-on, QR di accesso, certificati, database e log non redatti. Prima di allegare immagini ritaglia l'interfaccia della TV ed escludi casa, persone e account. Non pubblicare link personali per riprodurre un errore: descrivi le caratteristiche della sorgente e usa un campione pubblico appropriato.

## Regole editoriali

Una frase testato deve indicare modello, versione ed evidenza. Una lista non è una raccolta di stream verificati. Non promettere cataloghi premium gratuiti. Mantieni fonti primarie, licenze, limiti e recupero. Conserva anche risultati negativi.

Per Essential esegui i test indicati nel README dell'esempio; per i documenti controlla link e istruzioni. Non trasformare un helper per un firmware in procedura universale.
